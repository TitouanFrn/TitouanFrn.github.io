Scénario 1 — Base temporelle pour l'échantillonnage

Projet Domotique & IoT - ESIEE Paris

Objectif et Description

Ce premier scénario consiste à mettre en place une base temporelle pour gérer le clignotement de la LED connectée sur la broche PA5 avec une période de l'ordre de 2 à 3 secondes.

L'utilisation d'un timer évite l'utilisation de boucles d'attente bloquantes (delay).

Justification des choix techniques et configuration

Le Timer 2 (TIM2) est configuré pour générer une interruption périodique. Les paramètres choisis (le prescaler et la période/ARR) permettent d'obtenir la base de temps souhaitée, fixée ici à 2 secondes.

Démarrage du Timer en mode Interruption

Le Timer est démarré avec l'activation des interruptions juste avant la boucle infinie while(1) dans le programme principal (main) à l'aide de la fonction suivante :

HAL_TIM_Base_Start_IT(&htim2);

Gestionnaire d'interruption et Fonction Callback (ISR)

La fonction de rappel (callback) HAL_TIM_PeriodElapsedCallback est appelée automatiquement par la bibliothèque HAL. Elle permet de basculer l'état de la LED reliée à la broche PA5 :

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM2)
  {
    // Basculement de l'etat de la LED PA5
    HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);
  }
}

Justification et calcul de la période

La fréquence d'horloge d'entrée du timer est de FAPB = 16 MHz. La formule générale permettant de calculer la période temporelle T (le temps séparant deux interruptions) est la suivante :

$$T = \frac{(\text{Prescaler} + 1) \times (\text{Period} + 1)}{F_{\text{APB}}}$$

En injectant les paramètres choisis dans le code :

  • Prescaler = 1599
  • Period (ARR) = 19999
  • FAPB = 16 MHz

Le calcul donne :

$$T = \frac{(1599 + 1) \times (19999 + 1)}{16\ 000\ 000} = \frac{1600 \times 20\ 000}{16\ 000\ 000} = 2\text{ secondes}$$

La période obtenue est donc bien de 2 secondes, ce qui respecte la contrainte demandée.
