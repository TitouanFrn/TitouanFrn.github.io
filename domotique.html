Projet : Système Domotique & IoT

Présentation des scénarios d'usage et codes sources associés.

1. Objectif du projet

Ce projet a pour but de concevoir un système intelligent de gestion de présence et de confort thermique. L'architecture repose sur des microcontrôleurs connectés et des capteurs discrets pour automatiser l'habitat.

2. Scénarios mis en place

Scénario A : Détection de présence et éclairage adaptatif

But : Allumer progressivement l'éclairage de la pièce uniquement si la luminosité naturelle est insuffisante et qu'un mouvement est détecté.

Scénario B : Mode Absence / Économie d'énergie

But : Coupler les capteurs d'ouverture de porte et de température pour abaisser automatiquement le chauffage lorsque la pièce est inoccupée depuis plus de 30 minutes.

3. Extraits de Code

Voici un aperçu du script principal gérant l'analyse des capteurs :

// Exemple de code embarqué (C/C++ ou script de gestion)
#define CAPTEUR_PIN 4
#define RELAIS_LUMIERE 12

void setup() {
    pinMode(CAPTEUR_PIN, INPUT);
    pinMode(RELAIS_LUMIERE, OUTPUT);
    Serial.begin(115200);
}

void loop() {
    int presence = digitalRead(CAPTEUR_PIN);
    if (presence == HIGH) {
        digitalWrite(RELAIS_LUMIERE, HIGH);
        Serial.println("Mouvement détecté : Allumage de la lumière.");
    } else {
        digitalWrite(RELAIS_LUMIERE, LOW);
    }
    delay(1000);
}
