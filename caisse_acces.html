2. Accès par PIN et sessions de caisse

Connexion, création d'un restaurant et gestion des sessions.

Le portail

La page d'accueil propose deux choix : se connecter avec un code PIN, ou créer un nouveau restaurant.

Connexion par PIN

  1. L'utilisateur saisit 6 chiffres (la saisie est refusée si la longueur est différente).
  2. L'application cherche dans restaurants la ligne dont pin_code correspond.
  3. Si elle existe, l'identifiant et le nom du restaurant sont enregistrés dans le localStorage et l'utilisateur entre dans l'application.
  4. Sinon, un message « Code PIN introuvable » s'affiche.

Création d'un restaurant

  1. On vérifie qu'aucun restaurant du même nom n'existe déjà (sinon on invite à utiliser son PIN).
  2. Un code à 6 chiffres est tiré au hasard, puis contrôlé : s'il est déjà pris, on en tire un autre.
  3. Le restaurant est inséré et le code est affiché avec un bouton de copie.
newPinCode = Math.floor(100000 + Math.random() * 900000).toString();
Le PIN est aussi rappelé dans la page d'aide intégrée, pour pouvoir connecter la cuisine ou l'historique sur un autre appareil.

Sessions de caisse

Une session regroupe les commandes d'un service. Depuis la page « Sessions », on peut :

  • Ouvrir une nouvelle session (statut open) : son identifiant et son nom sont mémorisés comme session courante.
  • Reprendre une session existante.
  • Supprimer une session, ce qui efface aussi ses commandes et leurs lignes (voir la page Architecture).
