Scénario 2 — Gestion des modes HOME / AWAY, EXTI et Alarme PIR

Projet Domotique & IoT - ESIEE Paris

Objectif et Description

Ce second scénario intègre la gestion de deux modes de fonctionnement pour la maison intelligente :

  • MODE HOME : La maison est occupée ; les détections de mouvement par le capteur PIR sont considérées comme normales et ne déclenchent aucune alarme.
  • MODE AWAY : La maison est inoccupée ; toute détection de mouvement par le capteur PIR active immédiatement une alarme intrusion (activation du buzzer et clignotement de la LED d'alarme de manière non bloquante).

Schéma fonctionnel du système d'alarme et des modes HOME / AWAY

Le basculement entre ces modes s'effectue à l'aide du bouton poussoir utilisateur de la carte géré par une interruption externe (EXTI), incluant une protection logicielle anti-rebond. Le système intègre également une surveillance continue d'un capteur de gaz via l'ADC.

Justification des choix techniques et configuration

1. Gestion du bouton utilisateur et filtrage anti-rebond

Le bouton poussoir (BT_Pin, broche PC13) est configuré en interruption externe. Pour éviter les faux déclenchements dus aux parasites mécaniques du bouton, une protection logicielle par mesure du temps écoulé (debouncing via HAL_GetTick()) est mise en place avec un seuil minimal de 200 ms.

Voici la fonction de rappel des interruptions externes (HAL_GPIO_EXTI_Callback) gérant le changement de mode et l'interception du capteur PIR :

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  if (GPIO_Pin == GPIO_PIN_13)
  {
    uint32_t current_time = HAL_GetTick();

    if ((current_time - last_interrupt_time) > 200)
    {
      last_interrupt_time = current_time;

      if (currentMode == MODE_HOME)
      {
        currentMode = MODE_AWAY;
      }
      else
      {
        currentMode = MODE_HOME;
        alarm_active = 0;
      }
    }
  }

  else if (GPIO_Pin == GPIO_PIN_0)
  {
    if (currentMode == MODE_AWAY)
    {
      alarm_active = 1;
    }
  }
}

2. Gestion non bloquante de l'alarme (Buzzer et LED)

Lorsque le système bascule en état d'alarme (suite à une intrusion en mode AWAY ou à une détection de gaz via l'ADC), le clignotement de la LED d'alarme et la commande du buzzer passif sont gérés de manière asynchrone dans la boucle infinie while(1), en s'appuyant sur HAL_GetTick() plutôt que sur des fonctions de temporisation bloquantes (delay).

while(1){
      if (alarm_active == 1)
      {
          uint32_t current_tick_alarm = HAL_GetTick();
          uint32_t current_toggle = HAL_GetTick();

          if (current_toggle - last_buzzer_toggle >= 1)
          {
              last_buzzer_toggle = current_toggle;
              HAL_GPIO_TogglePin(BUZZER_GPIO_Port, BUZZER_Pin);
          }
          if (current_tick_alarm - last_led_toggle >= 250)
          {
              last_led_toggle = current_tick_alarm;
              HAL_GPIO_TogglePin(LED_INTRUSION_GPIO_Port, LED_INTRUSION_Pin);
          }
      }
      else
      {
          // Réinitialisation des sorties si l'alarme est désactivée
          HAL_GPIO_WritePin(LED_INTRUSION_GPIO_Port, LED_INTRUSION_Pin, GPIO_PIN_RESET);
          HAL_GPIO_WritePin(BUZZER_GPIO_Port, BUZZER_Pin, GPIO_PIN_RESET);
      }
    }

Difficultés rencontrées et résolution (Câblage du Buzzer)

Au cours de la mise en œuvre de ce second scénario, nous avons initialement câblé le détecteur PIR sur la broche PA0, la LED d'alarme sur PA1 et le buzzer sur PA2. Cependant, lors des phases de test, nous avons constaté que le buzzer ne fonctionnait pas correctement.

Après des investigations à l'oscilloscope et au multimètre, nous avons mesuré une tension de sortie de seulement 1 V sur la broche PA2, ce qui s'est avéré insuffisant pour alimenter et commuter correctement le buzzer ainsi que les LED. Pour résoudre ce problème de tension, nous avons décidé de déplacer la commande du buzzer de la broche PA2 vers la broche PA4. Suite à cette modification matérielle, le signal de commande a retrouvé un niveau logique suffisant et l'ensemble du système (buzzer et LED d'alarme) a fonctionné de manière optimale.
