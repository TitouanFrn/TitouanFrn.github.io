Scénario 5 — Gestion de la fenêtre motorisée (Servomoteur, Bouton et Capteur d'humidité)

Projet Domotique & IoT - ESIEE Paris

Objectif et Description

Ce cinquième scénario introduit le contrôle d'une fenêtre motorisée à l'aide d'un micro-servomoteur. Son comportement dépend de plusieurs conditions combinées :

  • Commande manuelle : Un bouton poussoir permet à l'utilisateur de demander l'ouverture ou la fermeture de la fenêtre en mode HOME.
  • Sécurité pluie : Un capteur d'humidité (Steam Sensor) surveille la présence d'eau. En cas de détection de pluie, la fenêtre se ferme automatiquement et le reste tant que la condition persiste.
  • Mode Global (HOME / AWAY) : En mode AWAY, la fenêtre est systématiquement maintenue fermée pour des raisons de sécurité.
  • Supervision UART et LCD : L'état de la fenêtre (WINDOW OPEN / WINDOW CLOSED) est transmis en temps réel via la liaison série.

Configuration et intégration logicielle

1. Définitions et variables globales

Les broches associées au bouton de la fenêtre et au capteur d'humidité ont été configurées, de même que les états logiques et les seuils de déclenchement :

typedef enum {
    MODE_OPEN = 0,
    MODE_CLOSED = 1
} Etat_fenetre;

#define BT_FENETRE_Pin GPIO_PIN_11
#define BT_FENETRE_Port GPIOC

#define SENSOR_Pin GPIO_PIN_7
#define SENSOR_Port GPIOA

#define HUMIDITE_THRESHOLD 1000

volatile Etat_fenetre currentEtat = MODE_CLOSED;
volatile uint32_t last_interrupt_time_2 = 0;
volatile uint8_t fenetre_active = 0;
uint32_t adc_humidite_val = 0;

2. Acquisition analogique (ADC1) et Pilotage du Servomoteur

La fonction d'acquisition ADC a été adaptée pour gérer plusieurs canaux (canal 7 pour l'humidité et canal 8 pour le gaz). Le servomoteur est quant à lui piloté via un signal PWM par modification de la largeur d'impulsion :

uint32_t Read_ADC(uint32_t channel)
{
    ADC_ChannelConfTypeDef sConfig = {0};
    sConfig.Channel = channel;
    sConfig.Rank = 1;
    sConfig.SamplingTime = ADC_SAMPLETIME_3CYCLES;
    HAL_ADC_ConfigChannel(&hadc1, &sConfig);
    
    uint32_t val = 0;
    HAL_ADC_Start(&hadc1);
    if (HAL_ADC_PollForConversion(&hadc1, 10) == HAL_OK)
    {
        val = HAL_ADC_GetValue(&hadc1);
    }
    HAL_ADC_Stop(&hadc1);
    return val;
}

void Set_Servo_Angle(uint16_t pulse_width)
{
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, pulse_width);
}

3. Logique principale et gestion des interruptions

Dans la boucle principale (while(1)), le système interroge périodiquement le capteur d'humidité. Les interruptions sur les boutons gèrent le changement de mode et l'ouverture/fermeture manuelle :

uint32_t current_tick = HAL_GetTick();
if (current_tick - last_adc_read >= ADC_READ_INTERVAL)
{
    last_adc_read = current_tick;
    adc_humidite_val = Read_ADC(ADC_CHANNEL_7);
    uint8_t previous_gaz_state = fenetre_active;
    
    if (adc_humidite_val > HUMIDITE_THRESHOLD)
    {
        fenetre_active = 0;
        if (previous_gaz_state == 0)
        {
            char gas_msg[50];
            sprintf(gas_msg, "[ALERTE] humidite detectee! Valeur: %lu\r\n", adc_humidite_val);
            HAL_UART_Transmit(&huart2, (uint8_t*)gas_msg, strlen(gas_msg), 100);
        }
    }
}

if (fenetre_active == 1) {
    Set_Servo_Angle(1900); // Fenetre ouverte
} else {
    Set_Servo_Angle(750);  // Fenetre fermee
}


void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == BT_MODE_Pin)
    {
        uint32_t current_time = HAL_GetTick();
        if ((current_time - last_interrupt_time) > 200)
        {
            last_interrupt_time = current_time;
            char mode_msg[40];
            if (currentMode == MODE_HOME)
            {
                currentMode = MODE_AWAY;
                currentEtat = MODE_CLOSED;
                fenetre_active = 0;
                sprintf(mode_msg, "Mode : AWAY \r\n");
            }
            else
            {
                currentMode = MODE_HOME;
                alarm_active = 0;
                currentEtat = MODE_CLOSED;
                sprintf(mode_msg, "Mode : HOME \r\n");
            }
            HAL_UART_Transmit(&huart2, (uint8_t*)mode_msg, strlen(mode_msg), 100);
        }
    }
    
    else if (GPIO_Pin == BT_FENETRE_Pin)
    {
        uint32_t current_time_2 = HAL_GetTick();
        if ((current_time_2 - last_interrupt_time_2) > 500)
        {
            last_interrupt_time_2 = current_time_2;
            char fenetre_msg[40];
            if (currentMode == MODE_HOME)
            {
                if (currentEtat == MODE_CLOSED)
                {
                    currentEtat = MODE_OPEN;
                    fenetre_active = 1;
                    sprintf(fenetre_msg, "Fenetre ouverte \r\n");
                }
                else
                {
                    currentEtat = MODE_CLOSED;
                    fenetre_active = 0;
                    sprintf(fenetre_msg, "Fenetre fermee \r\n");
                }
                HAL_UART_Transmit(&huart2, (uint8_t*)fenetre_msg, strlen(fenetre_msg), 100);
            }
            else
            {
                currentEtat = MODE_CLOSED;
                fenetre_active = 0;
            }
        }
    }
}

Difficultés rencontrées et résolutions

  • Conflit de brochage du bouton : Initialement, le bouton de la fenêtre était configuré sur la broche PC0, ce qui générait un conflit avec d'autres fonctions de la carte. Le problème a été résolu en basculant le bouton sur la broche PC11, garantissant un fonctionnement stable des interruptions.
  • Calibrage du servomoteur : Pour obtenir une ouverture et une fermeture complètes et franches de la maquette de la fenêtre, plusieurs essais empiriques ont été nécessaires afin d'ajuster précisément les valeurs de largeur d'impulsion PWM (fixées à 750 pour la position fermée et 1900 pour la position ouverte).
