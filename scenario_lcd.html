Ajout — Gestion de l'affichage LCD I2C

Projet Domotique & IoT - ESIEE Paris

Objectif et Description

Cet ajout intègre un écran LCD 16x2 piloté par une interface I2C au système domotique sur STM32. L'objectif est d'offrir un retour visuel en temps réel à l'utilisateur concernant :

  • Le mode de fonctionnement actuel du système (MODE: HOME ou MODE: AWAY).
  • L'état opérationnel de la fenêtre (Fenetre ouverte ou Fenetre fermee).
  • Les alertes critiques prioritaires (ALERTE INTRUSION, ALERTE GAZ, ALERTE HUMIDITE).
  • Un message de bienvenue personnalisé au démarrage du système.

Configuration et intégration logicielle

1. Intégration des fichiers pilotes (i2c-lcd.h et i2c-lcd.c)

L'utilisation de l'écran LCD I2C a nécessité l'ajout de la bibliothèque dédiée comprenant les fonctions bas-niveau d'initialisation, d'envoi de commandes/caractères, de positionnement du curseur (lcd_put_cur) et d'effacement (lcd_clear()). Ces fichiers ont été inclus dans les en-têtes du fichier main.c :

#include "i2c-lcd.h"

2. Séquence d'initialisation et message d'accueil dans le main

Au démarrage de la carte, après l'initialisation des périphériques matériels (I2C, GPIO, ADC, TIM, UART), l'écran est initialisé et affiche un message d'accueil temporaire avant de basculer sur l'affichage dynamique :

lcd_init();
lcd_clear();
HAL_Delay(50);

lcd_put_cur(0, 0);
lcd_send_string("Bonjour Lisa");
HAL_Delay(1000);
lcd_clear();
lcd_put_cur(0, 0);
lcd_send_string("Bienvenue");
HAL_Delay(1000);

3. Gestion de l'affichage dynamique par drapeau (update_lcd_flag)

Pour éviter de saturer le bus I2C et d'entraîner un scintillement permanent de l'écran, un mécanisme de drapeau (update_lcd_flag) a été mis en place. L'écran n'est rafraîchi dans la boucle principale while(1) que lorsqu'un événement modifie l'état du système (changement de mode, détection de gaz/humidité ou action sur le bouton de la fenêtre) :

if (update_lcd_flag == 1)
{
    update_lcd_flag = 0;
    lcd_clear();
    HAL_Delay(2);

    lcd_put_cur(0, 0);
    if (currentMode == MODE_HOME) {
        lcd_send_string("Mode: HOME");
    } else {
        lcd_send_string("Mode: AWAY");
    }

    lcd_put_cur(1, 0);
    if (alarm_active == 1) {
        lcd_send_string("ALERTE INTRUSION");
    }
    else if (gaz_active == 1) {
        lcd_send_string("ALERTE GAZ");
    }
    else if (hum_active == 1) {
        lcd_send_string("ALERTE HUMIDITE");
    }
    else if (currentEtat == MODE_OPEN) {
        lcd_send_string("Fenetre ouverte");
    }
    else {
        lcd_send_string("Fenetre fermee");
    }
}

Difficultés rencontrées et résolutions

  • Problème d'affichage initial (Carrés blancs / Écran vide) :
    Problème : Au premier branchement, l'écran affichait uniquement une ligne de carrés blancs ou restait totalement noir.
    Résolution : Ce comportement a été corrigé en ajustant finement la vis du potentiomètre de contraste de couleur bleue situé à l'arrière du module I2C pour trouver la plage de visibilité optimale des caractères, combiné à une vérification rigoureuse de l'ordre d'initialisation de l'I2C dans le code.
  • Conflit entre l'affichage LCD et les trames UART :
    Problème : L'utilisation initiale d'une fonction globale combinée envoyant simultanément des messages longs sur l'UART et des chaînes de caractères inadaptées au format de l'écran 16x2 effaçait le LCD en boucle.
    Résolution : Dissociation des flux : l'écran affiche désormais des libellés courts et optimisés (16 caractères max par ligne) gérés par des conditions strictes, tandis que les messages détaillés d'alerte sont transmis en arrière-plan via la liaison série UART.
  • Erreurs de syntaxe et d'imbrication lors de la fusion du code :
    Problème : L'ajout des conditions multiples pour le gaz, l'humidité et les alertes a généré des erreurs de compilation (accolades mal fermées, variables redondantes comme welcome_msg déclarées en double).
    Résolution : Nettoyage de la structure de la boucle while(1), suppression des variables intermédiaires obsolètes et structuration propre des blocs if / else if / else pour l'affichage séquentiel des priorités.
