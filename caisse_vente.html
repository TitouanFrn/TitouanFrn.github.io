3. Terminal de caisse et gestion du menu

Panier, tickets, émojis automatiques et édition du menu.

Le terminal de caisse

La page /caisse charge le menu, puis le composant POSClient gère tout l'affichage : grille de plats, filtres de catégories et panier.

  1. L'utilisateur choisit une catégorie (ou « Tous ») et touche les plats pour les ajouter au panier.
  2. Le total est recalculé en direct : cart.reduce((sum, item) => sum + item.price * item.quantity, 0).
  3. À la validation, la commande est créée avec le statut pending, puis ses lignes sont insérées dans order_items.
  4. Un message de succès affiche le numéro de ticket pendant 4 secondes et le panier est vidé.

Numéro de ticket

Les tickets de caisse commencent par CB. Le numéro vient du nombre de commandes déjà passées dans la session :

const currentCount = count || 0;
const calculatedTicketNumber = `CB${(currentCount % 100) + 1}`;

La numérotation recommence donc à 1 après 100 tickets.

Interface intelligente

Émoji automatique

Si un plat n'a pas d'image, l'application lit sa catégorie et son nom pour choisir un émoji (burger, frites, pizza, boisson, dessert…), et affiche 🍽️ par défaut.

if (text.includes("burger")) return "🍔";
if (text.includes("pizza")) return "🍕";
if (text.includes("boisson") || text.includes("soda")) return "🥤";
return "🍽️";

Couleur de catégorie

Chaque catégorie reçoit une couleur stable, calculée par un hash de son nom, puis ramenée à une palette. Une même catégorie a donc toujours la même couleur, sans réglage.

let hash = 0;
for (let i = 0; i < cat.length; i++) { hash = cat.charCodeAt(i) + ((hash << 5) - hash); }
const index = Math.abs(hash) % palettes.length;

Gestion du menu

La page /gestion-menu permet de créer, modifier et supprimer les plats : nom, prix, catégorie, et image par URL ou simple émoji. La suppression d'un plat retire d'abord ses lignes de commande pour respecter les clés étrangères.
